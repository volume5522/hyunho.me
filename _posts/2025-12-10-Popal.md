# WDSS (Web Drone Show Simulator)

기획부터 검증까지 한 화면에서 끝내는 드론 쇼 웹 제작 서비스

- **Github** : https://github.com/MW-1st  
- **Notion** : https://www.notion.so/WDSS-Project-DroneFactory-2519421e3b718077a932da9270ab6944  
- **개발 인원** : 6명  
- **기간** : 2025.08 ~ 2025.09  

---

## 핵심 기여

- Unity 기반 모놀리식 구조를 **서버-클라이언트 구조로 분리**
- **ASP.NET Core 기반 GCS 서버 설계 및 구현**
- Web–Unity–ESP32 간 **실시간 통신 구조 구축**
- **CPU 사용률 85% → 25% 감소**

---

## 역할

- 팀장으로 구조 설계 및 개발 방향 주도  
- C# 기반 GCS 서버 및 통신 로직 구현  

---

## 문제 상황

- Unity 내부에 모든 기능이 포함된 **모놀리식 구조**
- CPU 사용률 85% 이상, FPS 저하
- 실 드론 적용 불가능한 구조

---

## 해결 과정

- 중앙 제어 로직을 **ASP.NET Core 서버로 완전 분리**
- Unity를 **렌더링 전용 Viewer로 역할 축소**
- WebSocket / TCP / UDP 기반 통신 구조 설계

---

## 결과

- CPU 사용률 **85% → 25% 감소**
- 서버 리소스 **70% 절감**
- 실 드론 적용 가능한 구조 확보

---

## 아키텍처

Web Editor → FastAPI(OpenCV) → PostgreSQL/Redis →  
**ASP.NET GCS 서버 → Unity / ESP32 Drone**
